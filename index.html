Каскадні таблиці стилів (Cascading Style Sheets, CSS) — це формальна мова опису зовнішнього вигляду документа, створеного за допомогою мови розмітки. Завдяки CSS розробники відокремлюють логічну розмітку структури сторінки від візуального дизайну, що забезпечує гнучкість, централізоване керування та високу швидкість адаптації під будь-які екрани.

Принцип каскадності дозволяє застосовувати кілька стильових правил до одного елемента, при цьому пріоритет визначається специфічністю селекторів та порядком їх завантаження в браузер. У цій практичній роботі опрацьовуються базові властивості шрифтового оформлення, відступів, меж, фонів та інтерактивних станів.

1. Стильові властивості таблиць та структурних об'єктів

Відповідно до умов практичної роботи №9, таблиця повинна мати абсолютно прозорий фон, штрихову межу (штрихова рамка) товщиною 3 пункти (3pt dashed), шрифт Courier з розміром 90% від базового. Оформлення першого рядка передбачає центральне вирівнювання з напівжирним накресленням шрифту, тоді як інші рядки вирівнюються по центру зі звичайним шрифтом.

1 Документ (body) Світлосірий фон, малюнок у кутку без повтору background: #d3d3d3 url(...) no-repeat right bottom Перевірено

4 Заголовок 2-го рівня (h2) Verdana, 12pt, світлосиній, вліво, 1 см, нахилений color: #1e90ff; font-style: italic; Перевірено
5 Посилання (a) Без підкреслення, bold, hover-ефекти text-decoration: none; a:hover { ... } Перевірено

2. Інтерактивні посилання та псевдоклас :hover

Особлива увага приділяється псевдокласам гіперпосилань. За початкового стану посилання не мають підкреслення і є напівжирними. При наведенні курсора миші (:hover) динамічно змінюється колір, гарнітура на Georgia та збільшується розмір шрифту до 12pt:

3. Марковані списки та контрольні властивості

Нижче наведено приклад маркованого списку із квадратними маркерами, що відповідає першому завданню контрольного блоку:

  • Селектор: ul { list-style-type: square; line-height: 130%; }
  • Використання растрового маркера: list-style-image: url('2.jpg');
  • Керування міжрядковим інтервалом через властивість line-height.

Завдяки цьому сторінка демонструє повну відповідність навчальним стандартам дисципліни.

style.css Правила оформлення об'єктів згідно завдання 
/* ========================================================
   ПРАКТИЧНА РОБОТА №9. ФАЙЛ СТИЛІВ: style.css
   Тема: CSS візуальне оформлення об’єктів
   ======================================================== */

/* 1. Документ: фон світлосірий, фоновий малюнок без повторень у правому нижньому куті */
body {
    background-color: #d3d3d3;
    background-image: url('bg.png');
    background-repeat: no-repeat;
    background-position: right bottom;
    background-attachment: fixed;
}

/* 2. Текст: Courier, 10pt, темносиній, вліво, абзацний відступ 1 см */
p {
    font-family: 'Courier New', Courier, monospace;
    font-size: 10pt;
    color: #00008b; /* Темносиній колір */
    text-align: left;
    text-indent: 1cm;
}

/* 3. Заголовки 1-го рівня: Verdana, 14pt, чорний, вліво, відступ 1 см, напівжирний */
h1 {
    font-family: Verdana, sans-serif;
    font-size: 14pt;
    color: #000000;
    text-align: left;
    text-indent: 1cm;
    font-weight: bold;
}

/* 4. Заголовки 2-го рівня: Verdana, 12pt, світлосиній, вліво, відступ 1 см, напівжирний нахилений */
h2 {
    font-family: Verdana, sans-serif;
    font-size: 12pt;
    color: #1e90ff; /* Світлосиній колір */
    text-align: left;
    text-indent: 1cm;
    font-weight: bold;
    font-style: italic;
}

/* 5. Посилання: без підкреслення, напівжирний, прозорий фон */
a {
    text-decoration: none;
    font-weight: bold;
    background-color: transparent;
    color: #00008b;
}

/* При наведенні курсора: зміна кольору, гарнітури та розміру шрифту */
a:hover {
    color: #dc2626;
    font-family: Georgia, serif;
    font-size: 12pt;
}

/* 6. Таблиці: фон прозорий, рамка штрихова 3 пт, шрифт Courier 90% */
table {
    background-color: transparent;
    border: 3pt dashed #00008b;
    border-collapse: collapse;
    font-family: 'Courier New', Courier, monospace;
    font-size: 90%;
    width: 100%;
}

th, td {
    border: 1pt dashed #00008b;
    padding: 6px 12px;
}

/* Оформлення першого рядка: по центру, шрифт напівжирний */
table tr:first-child, table th {
    text-align: center;
    font-weight: bold;
}

/* Оформлення інших рядків: по центру, шрифт нормальний */
table tr:not(:first-child) td {
    text-align: center;
    font-weight: normal;
}

Теоретичні відомості до практичної роботи №9

Швидка шпаргалка для захисту роботи перед викладачем.

1. Одиниці вимірювання в CSS

pt (пункти): традиційна типографічна одиниця (1 pt = 1/72 дюйма). Часто зустрічається у навчальних методичках для фіксованого розміру тексту.
cm (сантиметри): абсолютна фізична одиниця, яка в браузері прив'язана до розрахункового DPI (96px = 2.54cm).
% (відсотки): відносна одиниця, що обчислюється від розміру шрифту батьківського контейнера (наприклад, 90% для таблиць).

2. Властивість background

Складається з кількох підвластивостей:
• background-color: #d3d3d3 — заливка кольором.
• background-image: url(...) — шлях до малюнка.
• background-repeat: no-repeat — заборона тиражування.
• background-position: right bottom — позиціонування у правому нижньому куті.

3. Псевдокласи посилань (LVHA)

Щоб псевдокласи працювали коректно, слід дотримуватись класичного порядку L-V-H-A:
1. :link — звичайне невідвідане посилання.
2. :visited — посилання, яке користувач уже відкривав.
3. :hover — стан при наведенні курсора.
4. :active — момент натискання кнопки миші.

4. Рамки таблиці (border-style)

Значення dashed створює штриховану лінію, на відміну від dotted (крапкова) або solid (суцільна). Властивість border-collapse: collapse з'єднує подвійні рамки комірок в одну лінію.
